# Always Visible Preview & Persistent SVG Result View

Date: 2026-08-31 02:43

## Objective

Ensure that the input original image, processing state, and vector result (SVG) remain continuously visible and accessible across all parameter adjustments and scroll depths in the Vektro web application.

## Motivation & UX Bottlenecks

1. **SVG Disappearance during Live Re-Processing**:
   When adjusting sliders or toggles in `IllustrationPanel` or `PixelartPanel`, `pending = true`. Previously, `Preview.jsx` unmounted the vector SVG and rendered `<ProcessingPlaceholder>`, destroying the user's visual feedback loop while waiting for WASM worker computation.
2. **Viewport Overflow & Scroll Loss**:
   As users scroll down long control sections (6-band equalizer sliders, auto-tuning toggles, fine tolerance settings), the preview section (`.preview`) gets pushed out of the browser viewport.
3. **Responsive Canvas Max-Height**:
   Large high-res SVGs can expand canvas containers beyond viewport height, forcing manual page scrolling to view the whole output.

## Planned Changes

### 1. Persistent SVG Result Rendering (`web/views/Preview.jsx`)
- Update `Preview.jsx` so `<ProcessingPlaceholder>` is rendered ONLY on initial image load when `!svg` and `pending` are true.
- When `svg` exists and `pending` becomes true (live parameter update), maintain the rendered SVG in `resultBox` with `stale={pending}` state (`opacity: 0.45` CSS transition), showing the progress bar below without unmounting or flickering the vector result.

### 2. Sticky Preview Container (`web/assets/style.css`)
- Apply sticky layout positioning to `.preview`:
  ```css
  .preview {
    position: sticky;
    top: 1rem;
    align-self: start;
    z-index: 10;
  }
  ```
- Ensure multi-column layout or responsive container handles sticky positioning without layout clipping on both desktop and mobile viewports.

### 3. Viewport-Adaptive Canvas Heights (`web/assets/style.css`)
- Adjust `.canvas-box canvas` and `.canvas-box svg` max-height to dynamic viewport units:
  ```css
  .canvas-box {
    max-height: clamp(240px, 48vh, 520px);
  }
  ```
- Ensure checkerboard background and clickable SVG container fit neatly within the sticky container bounds.
