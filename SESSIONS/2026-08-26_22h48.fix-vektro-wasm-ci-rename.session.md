# Fix Vektro WASM & CI Rename References

Started 2026-08-26 22h48. Planned; awaiting user approval.

## Context & Objectives

During the project rename from `img2svg` to `vektro`, `scripts/web-smoke.mjs` was updated to import `vektro.js`, but WASM compilation targets in GitHub Actions (`build.yml`), `web/services/worker.js`, `scripts/web-smoke.mjs`, and committed `web/pkg/` artifacts were still naming the output module `img2svg`.

This resulted in CI failure:
`Error [ERR_MODULE_NOT_FOUND]: Cannot find module '.../web/pkg/vektro.js' imported from .../scripts/web-smoke.mjs`

The goal of this session is to complete the WASM package and CI pipeline rename from `img2svg` to `vektro`.

---

## 1. WASM Build & Web Worker Updates

- Update `.github/workflows/build.yml`:
  - Change `wasm-pack build --out-name img2svg` to `--out-name vektro`.
  - Update API check step from `web/pkg/img2svg.d.ts` to `web/pkg/vektro.d.ts`.
- Update `web/services/worker.js`:
  - Import `../pkg/vektro.js` instead of `../pkg/img2svg.js`.
- Update `scripts/web-smoke.mjs`:
  - Read `vektro_bg.wasm` instead of `img2svg_bg.wasm`.

---

## 2. CI Release Pipeline Updates

- Update `.github/workflows/release.yml`:
  - Binaries naming: `vektro-v${{ needs.bump.outputs.version }}-${{ matrix.target }}`.
  - Executable path checks: `target/${{ matrix.target }}/release/vektro.exe` and `vektro`.
  - Web release bundle archive: `vektro-v${{ needs.bump.outputs.version }}-web.tar.gz`.

---

## 3. Regenerate WASM Package Artifacts

- Run `wasm-pack build --release --target web --out-dir web/pkg --out-name vektro -- --no-default-features --features wasm,illustration`.
- Remove legacy `img2svg.*` files in `web/pkg/` and commit new `vektro.*` files (`vektro.js`, `vektro.d.ts`, `vektro_bg.wasm`, `vektro_bg.wasm.d.ts`, `package.json`).
