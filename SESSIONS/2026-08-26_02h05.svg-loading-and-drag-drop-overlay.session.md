## 1. SVG Loading Fix

### Problem Analysis
In `web/services/converter.js`, `load(blob, name)` calls `createImageBitmap(blob)`.
When `blob` is an SVG (`image/svg+xml`):
- SVGs without explicit pixel `width`/`height` (e.g. `%` dimensions or `viewBox`-only) cause `createImageBitmap` in Chromium/WebKit browsers to freeze/hang the main thread in layout resolution loops.
- `createImageBitmap` fails silently or produces 0x0 dimensions for certain SVG structures.

### Solution
Replace direct `createImageBitmap(blob)` with a safe multi-stage image decoder:
- **SVG Detection**: Identify `image/svg+xml` or `.svg` blobs.
- **Safe Parsing**: Parse SVG text with `DOMParser`. Extract explicit pixel width/height or `viewBox` bounds. If missing or `%`, normalize SVG attributes to explicit pixel values.
- **Asynchronous `HTMLImageElement` decoding**: Load SVG via `URL.createObjectURL(safeBlob)` into `new Image()`, awaiting `onload` / `onerror`.
- **Canvas Rendering**: Draw decoded `HTMLImageElement` to 2D canvas to obtain RGBA pixel data for WASM.
- **Error Handling**: Gracefully show user-facing error message if SVG is corrupted or empty instead of hanging.

## 2. Full-Screen Drag & Drop Overlay

### Features
- Global drag event listeners on `window`/`document` for `dragenter`, `dragover`, `dragleave`, `drop`.
- `dragCounter` tracking to avoid flicker when dragging over child elements.
- Verify drag transfer contains files (`e.dataTransfer.types.includes('Files')`).
- Modern full-screen overlay component with semi-transparent backdrop, glassmorphism blur, subtle entry animations, upload icon, and text: *"Suelta la imagen para cargarla"*.

---

## 3. Image Replacement Confirmation Modal

### Features
- When a file is dropped, selected, or pasted while an image is already loaded in the workspace (`active` is true):
- Show a modal confirmation dialog: *"¿Reemplazar imagen actual?"*.
- Present the name of the new image and option to **Reemplazar** or **Cancelar**.
- Keyboard shortcuts: `Escape` closes/cancels, `Enter` confirms replacement.
- If confirmed: load the new image into the workspace.
- If cancelled: dismiss modal and preserve current workspace state.
